# 🎸 ギター・ハンドガイド

ギターのコードの押さえ方を、**3Dのリアルな手の形**で見せる練習アプリです（ウクレレ・ハンドガイドをもとに作り直し中）。
`index.html` をブラウザで開くだけで動きます（インストール不要）。

## いまの進み具合
1. ✅ **ギターの3Dモデル**（アコースティック・エレキの2種類。設定の⚙ →「ギター」で切り替え）
2. ✅ **左手・右手をギターに合わせる**（左手は6本弦の太いネックに合わせて形を計算。右手はピックを持って弾く）
3. ✅ **タブ譜からメロディを弾く**（サンプル6曲＋取り込み）

## コード譜から曲を取り込む（U-FRET など）
「練習」タブの下にある「📥 コード譜から曲を取り込む」から。読み取るのは**コード名だけ**で、歌詞は読み取らず保存もしません。1コード＝1小節として練習します。
- **① 取り込みボタン（いちばん手軽）**：「🎸 ギターに送る」をブラウザのお気に入り（ブックマーク）に1回だけ登録しておくと、コード譜のページでそれを押すだけで、曲名・コード進行・カポがこのアプリに入ります。読み取りは自分のブラウザの中で、自分が押した時だけ行い、サーバーは通しません（結果はこのアプリのURLの後ろ `#import=…` に付けて開きます）。パソコンはドラッグで登録、iPhone・Android は「ボタンのコードをコピー」してブックマークのURLに貼り付けます（手順はアプリ内の「登録のしかた」）。ネットで公開したページ（https）で使えます。
- **② コピーして取り込む**：コード譜の文字を全部選んでコピーし、「📋 クリップボードから取り込む」を押すだけ。または貼り付け欄に貼って「読み込む」。歌詞が混ざっていても、`[C]歌詞[G]歌詞` の形でも読めます。
- 「Capo 2」「カポ2」の書き込みがあれば、カポも自動で設定します。
- 押さえ方がないコード（分数コード `C/E`・テンション `E7(♭9)`・`m6` など）は近いコードで代用し、「代用：C/E→C」のように表示します。読めなかったものも表示します。
- 取り込んだ曲は「進行」の一覧（📥）に入り、この端末に残ります。🗑 で消せます。
- **コードの種類**：根音12（C・C♯・D・E♭・E・F・F♯・G・G♯・A・B♭・B）× メジャー／m／7／m7／maj7／sus4／6／sus2／add9／9／7sus4／dim／aug／m7♭5。開放弦のコード以外は、E型・A型（セーハ）・D型（dim・aug）の「動かせる形」から作っています（155コード。6・add9 は開放弦の形があるものだけ）。高いフレットのコード表は「4fr」のように起点を書きます。

## カポ
- コードのボタンの下の「カポ −／＋」で、カポをつけるフレット（なし〜9フレット）を選べます。
- 押さえ方（コードの形・タブ譜の数字）はそのまま、カポの分だけ上のフレットで押さえ、音もカポの分だけ高くなります。開放弦はカポが押さえます。
- 3Dにはカポ（ゴムのパッドと、ネックの裏からはさむばねの腕）が表示され、弦はカポの所でフレットに押しつけられます。
- コード名は押さえ方の名前のまま。実際に鳴る音の名前は「（カポ2・実際の音は D）」のように表示します。コード表の右上にも「カポ2」と出ます。

## カメラで見比べる
- 3D画面右上の「📷」で内カメラをオンにすると、3Dの横（スマホの縦向きでは下）に自分の映像が並びます。3Dの手と重ならないので、見比べながら練習できます。
- 「小窓にする」で、3Dの上に重ねる小さな窓にもできます（「並べる」で戻ります）。小窓はドラッグで好きな場所へ動かせて、「⤢」で大きさ（小・中・大）を変えられます。「⇋」で左右反転（鏡のように見える）、「3Dを合わせる」で3Dを正面＋左右反転にして、カメラに映る自分と同じ向きにします。
- 映像はこの端末の中で表示するだけで、どこにも送ったり保存したりしません。カメラは https のページ（GitHub Pages など）で使えます。

## ソロ（タブ譜のメロディ弾き）🎁 おまけ・開発中
- 右のパネルの「ソロ（開発中）」タブ。指の選び方や手の形はまだ調整中のおまけ機能です。数字＝押さえるフレット（0＝開放弦）、丸の色＝押さえる指。
- 「▶ 弾いてみせる」で、1小節カウントしてから、左手がその弦・フレットを押さえ、右手がピックでその弦だけを弾きます（表拍はダウン、裏拍はアップ。何本か同時の時はダウンでまとめて）。開放弦の音は、ナットのすぐ先が緑に光ります。
- 止まっている時は、タブ譜の数字を押すとその音の押さえ方が見られます。テンポ・速さ（×1〜×¼）も変えられます。
- **サンプル曲**（著作権の切れた曲。♫ はメロディ＋伴奏のソロギター）：きらきら星♫／歓喜の歌♫／ハッピーバースデー♫／聖者の行進♫／グリーンスリーブス♫／カノン♫／ジングルベル♫／禁じられた遊び♫（ベース音と3連符のアルペジオ。Amは5フレットのセーハのまま、メロディを薬指・小指で）
- **ソロギター（♫）**：左手は**コードの形を押さえたまま**弾きます（ソロギターの基本の弾き方）。伴奏もタブ譜に入っていて、1拍目（4拍子は3拍目にも）にコードのベース、メロディの合間（裏拍）に内側の弦（3弦など）のアルペジオが入ります。
  - 弾く音がコードの中にある時は、押さえている指のまま鳴らすだけ（指は動かない）。コードにない音だけ、空いている指（多くは小指）を足します。足せない時は、その弦の指だけ一瞬はなします。
  - 小さいF（1・2弦だけ人差し指でセーハ）、薬指・小指のG（人差し指が空くので、1弦1フレットを足すとそのままG7の形になる）など、ソロギターでよく使う押さえ方を使います。ベース（いちばん太い弦）の指はなるべく離しません。
  - コードの区間の中に、形のまま届かない音（例：Fを押さえたまま1弦5フレット）がある時だけ、その区間は1音ずつの押さえ方に切りかえます（途中で行ったり来たりしないように）。
  - 画面では、いま弾く所だけが光り、押さえているだけの所は丸の印だけになります。
- **右手（指弾き）**：ソロは、親指でベース（6・5・4弦）、人差し指＝3弦、中指＝2弦、薬指＝1弦を弾きます（クラシックギターの p・i・m・a）。ふさがっていれば隣の指。前腕はボディのおしり側・6弦側の縁の上を、表板に沿って寝かせて来ます（ギターの正面から突き出さない）。手首は手のひら側へ軽く（15°）曲げ、手は弦の上から1弦側（下）へ垂らします。親指が弦を移る時は、手ごと少し（1本で5mm）ついていきます。指は付け根40°・第二関節50°ほどの自然な曲げで弦の上から下り、手のひら側（6弦側・上）へはじきます。親指は指よりネック側に出て、ベース弦を下へ押して弾きます。小指は弾かず、薬指の後ろについていきます。指先はつけ根の並びと同じ順（人差し指がネック側、薬指がブリッジ側）に置き、指は横に折れずにまっすぐ前へ丸まります（指どうしが交差しない）。弾き終わった指は弦から5mm浮かせて戻り（鳴っている弦に触れて音を止めない）、次に弾く直前に弦へ下ります。指は音の35ms前から動き始め、音の時刻に弦を通り、50ms後に弾き終わって、180msで弦の所へ戻ります。親指が6弦を弾く時は手ごと少し6弦側へ寄ります。設定の「ソロの右手」でピックにも切り替えられます。
- **右手（ピック）**：ベースとメロディを同時に弾く時は、ピックがその間の弦も通るので、間の弦（押さえていればそのフレット、押さえていなければ開放）も小さく一緒に鳴ります。コードを押さえたままなら、たいていコードの音です。音と音の間の移動では、ピックを弦から3〜8mm浮かせます（弦をかすめない）。
- **検証のしかた**：曲ごとに、手の移動の回数と速さ、指の飛び（同じ指が短い時間で遠くへ）、指の広げすぎ（4フレット超）、隣り合う指のフレット差、指の順番を自動で数えます。右手は、ピックの先の軌道を1拍の1/96ごとにたどり、弾く弦に当たっているか・移動中に弦をこすっていないかを数えます。
- **ピックでは無理な曲**：「禁じられた遊び」は、6弦のベースと1弦のメロディを同時に弾く曲なので、ピックだと間の4本も鳴ってしまいます（本来は親指と3本の指で弾く曲）。
- **いちど離した指は、すぐ押さえ直さない**：コードの指を1音だけ離した時（その弦を別の音で弾くなど）、次の音ですぐ戻すのではなく、その弦をまた弾く時まで離したままにします。
- **押さえた指はすぐ離さない**：弾き終わった指も、その指を別の所で使う・その弦を別のフレットや開放で弾く・手の位置やコードが変わる・3拍たつ、のどれかまでは押さえたままにします。
- **「いま」と「次」**：3Dの手にかぶらないよう、上の見出しの下に小さく出します（「Cを押さえたまま　次：2弦・1フレット（人差し指）」など）。
- **取り込み**（「📥 タブ譜・楽譜を取り込む」）
  - 文字のタブ譜を貼り付け（`e|---0---3---|` のような6行。上が1弦）。リズムは数字の間隔から推定します。
  - MIDIファイル（.mid）：いちばん音の多いトラックの、いちばん高い音をメロディとして使います。ギターで弾ける高さにオクターブ単位でそろえます。
  - MusicXML（.musicxml / .xml / .mxl）：タブ譜（弦とフレット）が入っていればそのとおり、なければ自動で決めます。Guitar Pro や MuseScore の曲は MusicXML か MIDI で書き出すと取り込めます。
  - 取り込んだ曲はこの端末（ブラウザ）に残ります。「🗑 消す」で消せます。
- **左手の構え（2つの形）**：前後の音を見て、ポジションごとに選びます。どちらの形か・何ポジションかは、3D画面左下の「いま」に出ます。
  - **指を開く形**：4本の指を1フレットずつ開いて並べる。指のつけ根はネックの1弦側のふちに沿って平行に並び、指はアーチを描いて弦へ下ります。親指はネックの裏のまん中。小指まで使う時・4フレットにまたがる時・3本以上の弦を行き来する時に使います。
  - **斜めの形**：人差し指のつけ根をネックのふちに当て、小指側ほど少しネックから離れて手が斜めになり、指をのばして押さえます。押さえる音によって、人差し指のつけ根を支点に手の傾きだけ少し変わります。親指はネックの上から少しのぞきます。2〜3フレットの中で1〜2本の弦を弾く時に使います。
  - **待っている指**は、決まった点に指先を合わせるのではなく、力を抜いた形（つけ根を少しそらせ、第二関節で軽く曲げる）を基本に、弦に触れない高さ・だいたい自分のフレットの上になるよう曲げ角を少しだけ変えます（縮こまって「く」の字にならない）。
  - **音から音へ**：押さえに行く指は待っていた所からまっすぐ弦へ下り、離す指は少し遅れてゆっくり上がります（コードチェンジのように山なりに持ち上げない）。動く指の隣の指は、つられてほんの少し動きます。隣の指が押さえている間は、待つ指も少し低くなります。
  - **指が交差しないように**：同じ音が続く時は同じ指で押さえ続けます。指の順番（フレットが低いほど人差し指側、同じフレットなら太い弦ほど人差し指側）がくずれる押さえ方はしません。待っている指は、押さえている指の下にもぐらない場所で待ちます。小指が薬指と同じフレットを押さえる時などは、指を少しひねって弦の上にアーチを描き、隣の指にかぶさらないようにします。
  - どちらの形でも、手の位置はポジションの間ずっと同じ。押さえ終わった指はその場で2mmほど浮かせて待ち、開放弦を弾く時はその弦を押さえていた指だけを少し上げます。ポジションが変わる時だけ手ごとすべらせます。
- **弦・フレット・指の決め方**：人差し指の位置（ポジション）を音ごとに決め、1つのフレットに1本の指（人差し指〜小指）を割り当てます。手の移動・高いフレット・指の広げすぎが少なくなる組み合わせを、曲全体を見て選びます（`src/tab.js`）。

## ギターのモデル
- **アコースティック**：ドレッドノート（Martin D-28 を参考）。弦長645mm、ナット幅44.5mm、ボディ長508mm、アッパー292mm・ウエスト273mm・ロワー397mm、厚み115mm、サウンドホール直径100mm、20フレット（14フレットでボディにつながる）。スプルースの表板・ロゼッタ・べっこう柄のピックガード・ブリッジピン・3対3のヘッド（14°後ろへ傾く）。
  - 柄：ナチュラル／サンバースト／マホガニー／ブラック
- **エレキ（ストラト型）**：実物の1:1図面（Strat-Body-Front.pdf）から取ったボディの輪郭。全長460mm・幅322mm・厚み45mm、弦長648mm、ナット幅42mm、22フレット。ピックアップ3つ（ネック側491・まん中551・ブリッジ側607mm、ブリッジ側は斜め）、トレモロのねじ列とサドル、ノブ3つ・5段スイッチ・ジャックの位置も図面どおり。ピックガードは輪郭から作り、6連ペグのヘッド。
  - 柄：3トーンサンバースト／サンバースト＋べっこう／ホワイト／レッド／ソニックブルー／ブラック（指板はメイプルかローズウッド）
- **エレキ（レスポール型）**：1958〜60年型の1:1テンプレート（John Catto, 2006）から取ったボディ・ピックガード・ヘッドの輪郭。全長438mm・幅333mm、弦長628.65mm、ナット幅43mm、22フレット。表板はアーチ状に彫ってあり（縁からまん中へ約11.5mm盛り上がる）、ボディはネックのつけ根から3.5°後ろへ傾けてつける。ハムバッカー2つ・チューン・O・マチック・ストップテールピース・金色のノブ4つ・切り替えスイッチの位置も図面どおり。台形のインレイ、指板とボディのふちのバインディング、17°傾いたヘッドとトラスロッドカバー。
  - 柄：チェリーサンバースト／タバコサンバースト（トラ杢のメイプル）／ゴールドトップ／ブラック（金色の金具）
- **弦**：6本、太さは実物どおり（アコギ .012〜.053、エレキ .010〜.046）。巻き弦は色が違います（アコギはブロンズ）。
- **コード**：12の根音 × 14種類（下の「コード譜から曲を取り込む」参照）。弾かない弦は「×」（コード表と3D画面の弦の名前の横に表示し、音も鳴らしません）。

# 🎶 ウクレレ・ハンドガイド

ウクレレのコードの押さえ方を、**3Dのリアルな手の形**で見せる練習アプリです。
`index.html` をブラウザで開くだけで動きます（インストール不要）。

## できること
- **3Dの手で押さえ方を表示**：解剖学の計測値（指の骨の長さ・関節の曲がり方）をもとに、指の関節角度を計算して手の形を作ります。指先は真上から、他の弦に触れないように、無理のない角度で押さえます。
- **見る向きを切り替え**：ななめ／自分目線／正面（向かい合った先生から）／横から。画面を**ドラッグすると回せます**。左右反転もできます。
- **コード表**：3D画面の左下に、いまのコードの縦のコード表を小さく表示します（設定で消せます）。練習・曲デモの演奏中は「いま → 次 → その次」の3つを並べ、次のコードまで1拍を切ると次のコード表がオレンジに光ります。
- **全画面**：3D画面右上の「⛶」で全画面に。全画面では、コードのボタンと再生ボタンが3D画面の下に重なって表示されます（再生ボタンの左の曲名を押すと、練習と曲デモを切り替え）。「✕」かEscキーで元に戻ります。縦長のスマホでも、指板が見切れないように見える範囲を広げます。
- **自分で作る進行**：練習の「進行」で「✏️ 自分で作る」を選ぶと入力欄が出ます。コード名をスペースで区切って書くと（例：`C Am F G7`、1つ＝1小節）、その進行で練習できます。`Bb`・`A#`→B♭、`am`→Am のような書き方も読み取り、使えないコードは教えてくれます。書いた進行は次に開いた時も残ります。
- **54コード**：C・D・E♭・E・F・G・A・B♭・B × メジャー／m／7／m7／maj7／sus4（セーハも対応）
- **手を半透明に**：手を透かして、押さえる場所の印（指の色の丸）と、弦が指に当たって沈んでいるところ（光る輪）を見せます。
- **右手のストローク**：右手も3Dで表示。腕は止めたまま、手の甲を軸にして指先側を振り子のように回して弾きます（手の甲はあまり動きません）。手首は腕より少し遅れてムチのようにしなり、ダウンは大きく・アップは小さく、1拍目は少し強く、指先はダウンで伸びてアップで丸まり、毎回ほんの少しずつ振り幅がばらつきます。前腕はウクレレの尾側（ボディのおしり側）から、ボディの上の方をほぼ水平に横切って来ます（ひじは体の横で約90°）。ダウンは人差し指の爪、アップは指の腹で弦をこすります。「弾き語り練習」では、ダウン4つ／8ビート／カリプソ／バラードのパターンを選ぶと、↓↑の譜面が光り、音と右手の動きがリズムに合わせて動きます。弾かない拍は、手を少し浮かせて空振りします。
- **演奏デモ**：カノン（パッヘルベル。カノン進行、2回目からバイオリンの旋律）、朝日のあたる家（Am→C→D→F、3拍子。伴奏だけ）、12小節ブルース（E7・A7・B7。「スイング」でシャッフル。伴奏だけ）、グリーンスリーブス（3拍子・メロディ付き）、聖者の行進（8ビート・メロディ付き）、ハッピーバースデー・トゥー・ユー、きらきら星。どれも著作権の切れた曲で、ギターでよく弾かれる曲を選んでいます。1小節カウントしてから、コード譜が光り、左手のコードチェンジと右手のストロークが曲に合わせて動きます。
- **腕は手首の少し先まで**：両腕とも手首から先だけを見せ、その先はだんだん透明にして消しています。
- **スイング**：練習・曲デモで「スイング」を押すと、裏拍を少し遅らせて「タッカ・タッカ」とはずむリズムになります（音・手・光る位置すべて）。
- **アングル・2画面**：3D画面の左上「🎥」ボタンを押すたびに向きが変わります。「2画面」で左右に別の向きを同時に表示でき、どちらもドラッグで回せます。2本指（マウスは右ドラッグ）で平行移動、ピンチ（ホイール）で拡大。
- **設定（3D画面右上の⚙）**：背景（昼の砂浜・夕焼けの砂浜・夜の砂浜・海の家・野原）、ウクレレの柄（マホガニー・ハワイアンコア・スプルース・ブラック・パステル）、右手（いつも表示・演奏中だけ・表示しない）、2画面・半透明・指番号・左右反転・コード表のオン／オフ。選んだ設定は次に開いた時も残ります。速さ（×1〜×¼）は練習・曲デモの再生ボタンの横にあります。
- **右手の表示・スロー再生**：右手は「いつも表示／演奏中だけ／表示しない」を選べます。「速さ」で練習・演奏デモをふつう／3/4／1/2／1/4の速さで再生できます（音も手もいっしょにゆっくりになります）。
- **音と手がぴったり合う**：音を鳴らす時計（Web Audio）と同じ時計で手を動かし、スピーカーから聞こえるまでの遅れも計算に入れています。左手は、次のコードの音が鳴る瞬間にちょうど押さえ終わるように、少し前から動き始めます。
- **なめらかな動き**：右手の動きをならし、重い端末では動いている間だけ自動で解像度を下げます。曲で使うコードの手の形は演奏前に計算しておきます。
- **指がくっつかない**：指どうしがぶつからないように持ち方をシミュレーションし、同じフレットに並ぶ指は指の順番どおり斜めに並べます。
- **音で確認**：ジャラーンと鳴らす／1本ずつ鳴らす（画面タップ・スペースキーでも鳴ります）
- **コードチェンジ練習**：定番の進行を選んで▶。メトロノームに合わせて手が次のコードへ動きます。

## 背景・処理の軽さ
- **軽さ（画質）の3段階**：端末に合わせて自動で「きれい／ふつう／軽い」を選びます（スマホは「ふつう」、メモリやCPUが少ないスマホ・画面がとても細かいスマホ・弱いGPUは「軽い」、パソコンは「きれい」）。⚙ →「軽さ」で手動でも選べます（変えると読み込み直します）。
  - きれい：解像度1.5倍まで・ふち取りあり・影2048・手の表面を2回なめらかに・背景の絵は等倍・ギターの曲線24分割
  - ふつう：解像度1.25倍・影1024・手の表面を1回なめらかに（三角形の数が約3分の1）・背景の絵は半分・曲線12分割・木目の絵は半分
  - 軽い：解像度1倍・ふち取りなし・影なし・背景の絵は4分の1（模様の数も）・曲線8分割・木目の絵は4分の1
  - 見た目の違いはわずかですが、「ふつう」で三角形の数が約8.5万→2.6万、読み込み時間が約3分の1になります。
- **演奏中にカクつかない工夫**：手の形の先読み計算（1つ0.1〜0.3秒かかる）は、演奏中・ソロの準備中・手やカメラが動いている間は止めて、止まっている時だけ進めます。解像度の自動調整は3段階だけにして、変えるのは重い・軽いがしばらく続いた時だけ（解像度を変えること自体が重いため）。右手の振りの形と弦の音も、ひまな時に先に作っておきます。
- **なめらかな操作**：3Dの回転には慣性があり、指を離してもスッとなめらかに止まります。影は手やギターが動いた時だけ描き直し（カメラを回すだけなら前の影のまま）、手の形が変わっていない時は手の計算もしません。カメラを回している間も、重い端末では自動で解像度を下げます。スマホでは影を少し粗くして軽くしています。
- ウクレレは演奏する時と同じように立てて構え、指板が正面（客席）を向いています。
- 3Dの背景は実物大。ウクレレの約90cm下が地面（近くで見ると砂粒や草が見える）、砂浜では弾く人の後ろ約2.6mに波打ち際、その先に海と水平線。夕焼け・夜は光の色や明るさも変わり、海に太陽・月の光の道ができます。海の家は木のデッキと屋根・手すり、野原は草地と遠くの丘。画像ファイルは使わず、その場で描いています（選んだ時に初めて作ります）。
- 重い端末では、動いている間だけ自動で解像度を下げ、それでも重い時は影を切ります（解像度は最大1.5倍、影の細かさは控えめ）。
- 押さえる場所の印は作り置きして使い回し、毎コマ作り直さないので、長く演奏しても重くなりません。肌の質感も軽い方式にしています。

## 手とウクレレの形のしくみ
- **手**：関節に骨が入ったリアルな手の3Dモデル（WebXR Input Profiles の generic-hand、MIT License）を使い、
  関節の角度を計算で決めて動かしています。表面は細分割でなめらかにしています。
  - 骨の長さ・指の付け根の位置はモデルの実寸。第一関節は第二関節の約0.75倍だけ曲がる（小指は約0.6倍）という計測値を使用。
  - 指先は真上から、他の弦に触れないように、関節が無理な角度にならないように、の3つを満たす形を選びます。
  - **持ち方のシミュレーション**：手の向き（ひねり・傾き・回転）と位置を少しずつ変えながら、「指先が弦に届く」「関節に無理がない」「手のひらがネックにめり込まない」「手首が曲がりすぎない」「親指がネックの上の肩にかかり、先が上からのぞく」を合計して、いちばん無理のない持ち方を自動で選びます（`src/pose.js`）。
  - 親指は付け根・まん中・先の3つの関節を、人が実際に曲げられる範囲の中だけで動かして形を決めます（`src/thumb.js`）。
  - 手のひらはネックの裏側、ネックを親指と人差し指の股で深くはさみ、親指は付け根〜まん中の節をネックの上の肩（4弦Gの側）にかけて、先を上からのぞかせます。指は1弦（A）側からネックを回り込み、少し斜めに立てて弦を押さえます。前腕は体の側から来て、手首で曲がります。
- **ウクレレ**：コンサートサイズの実寸（Kala KA-C を参考）。弦長381mm、ボディ長281mm、アッパー152mm、ウエスト125mm、ロワー210mm、厚み70mm、サウンドホール直径52mm、18フレット。

## ファイルの構成（さわる人向け）
- `index.html` … 完成品（これだけで動きます）
- `src/` … 元のプログラム（`app.js` 画面・音、`pose.js` 手の形の計算、`handrig.js` 手のモデル、`uke.js` ウクレレのモデル、`view.js` 3D表示、`thumb.js` 親指、`strum.js` 右手のストローク、`data.js` コードと曲のデータ）
- `src/` を直したら `npm install` → `npm run build` で `index.html` を作り直します。
